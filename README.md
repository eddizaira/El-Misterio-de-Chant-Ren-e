# El-Misterio-de-Chant-Ren-e
Siete amigos — Kath, Nicole, José Frank, Diego, Shanti, Kevin y Eddizaira — celebran la víspera de Navidad en una cabaña aislada llamada Chant Renée. Durante la velada, José Baez bebe chocolate caliente y cae al suelo. Uno de los presentes lo ha envenenado. El grupo debe interrogarse entre sí para descubrir quién es el impostor antes del amanecer.
